이 프로젝트(정적 HTML 사이트)의 모든 `.html` 파일을 점검하라.

## 점검 항목

1. **제목(title)**: 각 HTML 파일에 `<title>` 태그가 존재하고 비어있지 않은지 확인.
2. **깨진 링크**: `<a href>`, `<img src>`, `<link href>`, `<script src>` 등에서 참조하는 내부 파일 경로가 실제로 존재하는지 확인. 외부 URL(http/https)은 형식만 확인하고 접속 여부는 검사하지 않는다.
3. **콘솔 에러**: claude-in-chrome 브라우저 도구로 각 페이지를 열어 콘솔 에러/경고(read_console_messages)를 확인한다. 브라우저 도구를 사용할 수 없는 환경이면 이 항목은 "확인 불가"로 표시하고 이유를 남긴다.

## 진행 방식

- 먼저 프로젝트 내 모든 `*.html` 파일을 찾는다.
- 파일별로 위 세 항목을 각각 점검한다.
- 브라우저 콘솔 점검이 필요하면 claude-in-chrome 스킬/도구를 사용해 로컬 파일을 열어 확인한다.

## 결과 보고 형식

파일별로 아래와 같은 마크다운 표로 정리해서 보고한다:

| 파일 | 제목 | 깨진 링크 | 콘솔 에러 | 상태 |
|---|---|---|---|---|
| index.html | 통과 | 통과 | 통과 | ✅ 통과 |
| about.html | 제목 없음 | `img/logo.png` 없음 | - | ❌ 수정 필요 |

- 상태는 세 항목이 모두 통과일 때만 "✅ 통과", 하나라도 문제가 있으면 "❌ 수정 필요"로 표시.
- 표 아래에 수정이 필요한 항목에 대해 구체적인 원인과 파일 위치를 짧게 정리한다.
- 코드를 임의로 수정하지 말고 점검 및 보고만 수행한다.
